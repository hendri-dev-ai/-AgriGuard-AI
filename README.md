AI-Powered Rice Disease Detection System

🚀 Deskripsi

AgriGuard AI adalah aplikasi berbasis Artificial Intelligence yang dirancang untuk membantu petani dalam mendeteksi penyakit pada tanaman padi secara cepat dan akurat melalui analisis gambar daun.

Dengan memanfaatkan teknologi Computer Vision dan Deep Learning, aplikasi ini mampu memberikan:

Deteksi penyakit secara otomatis
Tingkat kepercayaan hasil analisis
Rekomendasi penanganan
Strategi pencegahan

🎯 Tujuan utama:
Meningkatkan hasil panen dan mendukung ketahanan pangan melalui teknologi AI.

✨ Fitur Utama

✅ Scan Gambar Daun Padi
Upload atau ambil foto daun untuk dianalisis secara otomatis

✅ Deteksi Penyakit AI
Model AI mengidentifikasi penyakit seperti:

Blas Padi
(Tambahkan penyakit lain jika ada)

✅ Tingkat Keyakinan (Confidence Score)
Menampilkan persentase akurasi prediksi

✅ Rekomendasi Penanganan
Solusi berbasis praktik pertanian terbaik

✅ Pencegahan Penyakit
Langkah preventif untuk menghindari penyebaran
